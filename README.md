
# Multilingual Newspaper Data Analysis & Insights Dashboard

## Project Overview

The **Multilingual Newspaper Data Analysis & Insights Dashboard** project explores newspaper data across multiple languages, publications, and editions, with a geographical focus on Mangalore and Goa.

The project applies data analysis and visualization techniques to organize newspaper-related information, examine patterns across languages and publications, and present analytical insights through interactive dashboards.

Using Microsoft Excel and Tableau, the project demonstrates how structured data can be transformed into meaningful visualizations to support exploration, comparison, and reporting.

## Objectives

- Analyze newspaper data across multiple languages and publications.
- Explore differences between newspaper editions.
- Examine the distribution of newspapers across languages.
- Compare publication-related patterns within the available dataset.
- Develop interactive dashboards for data exploration and reporting.
- Present multilingual newspaper information through clear visualizations.

## Dataset Overview

The dataset contains **500 records** covering multiple newspapers, languages, and editions.

### Dataset Summary

| Attribute | Details |
|---|---|
| Total records | 500 |
| Languages covered | 6 |
| Newspapers covered | 11 |
| Editions covered | 6 |
| Geographical focus | Mangalore and Goa |
| Data domain | Newspaper and publication analysis |

The dataset provides a structured basis for exploring the distribution of newspaper publications across languages and editions.

## Methodology

The project follows a structured data analysis workflow:

1. **Data Understanding:** Examine the dataset structure, records, and attributes.
2. **Data Cleaning:** Identify and address missing, inconsistent, or duplicate values where applicable.
3. **Data Preparation:** Organize newspaper, language, and edition information for analysis.
4. **Exploratory Data Analysis:** Investigate the distribution of records across relevant categories.
5. **Comparative Analysis:** Explore differences among languages, newspapers, and editions.
6. **Data Visualization:** Develop charts and interactive dashboards in Tableau.
7. **Insights and Reporting:** Present findings in a format that supports data exploration and interpretation.

## Limitations

- The analysis is limited to the 500 records available in the dataset.
- Findings depend on the accuracy, completeness, and consistency of the source data.
- The dataset may not represent every newspaper or edition available in Mangalore or Goa.
- The analysis describes the available data and should not be interpreted as a complete representation of the newspaper industry.
