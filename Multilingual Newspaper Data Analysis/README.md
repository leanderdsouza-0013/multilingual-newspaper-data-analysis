# Multilingual Newspaper Data Analysis

A hands-on data analysis project using newspaper data to explore patterns across newspapers, languages, categories, headlines, advertisements, cover prices, and page counts.

## Tools Used
- Python
- Pandas
- Matplotlib
- Microsoft Excel
- Tableau

## Analysis
- Newspaper and category distribution
- Headline length analysis
- Multilingual headline analysis
- Advertisement analysis
- Cover price analysis
- Page count analysis
- Tableau dashboard visualization

## Dashboard
Built a Tableau dashboard to present key findings through interactive visualizations.

## Dataset
The main dataset contains 500 newspaper records covering 6 languages and 11 newspapers.
